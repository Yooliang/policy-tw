# 2026-10-28 Edge Function 部署：逐支記基準、單支重試

- 起因：Supabase 伺服器端抓 jsr.io 逾時，一天內整輪重跑 6 次；19 支裡只要 1 支失敗，全域 tag `edge-functions-deployed` 不動，下次合併又重部同一批。
- 裁決（小良哥 10-28「好」）：①`deploy-functions.mjs` 每支最多試 3 次、間隔 15／30 秒；②CI 帶 `DEPLOY_SHA`，每支成功各記 tag `edge-fn/<名稱>`；③`affected-functions.mjs` 對每支函式優先用自己的 tag 當基準（須比全域 base 新，否則用全域）；④全部成功後移動全域 tag 並清掉 `edge-fn/*`。
- 注意：「只比對函式實際引用到的檔案」本來就是 affected-functions 的做法（transitive import），沒有改。
- 失敗時往多部署倒：tag 讀不到、不是後代都退回全域 base。
