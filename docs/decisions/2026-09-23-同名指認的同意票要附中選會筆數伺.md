- **同名指認的同意票要附中選會筆數，伺服器收票當下核對**（協議 1.29.0）｜維護者 09-23 點頭。指認一票就採用，而讀同一份錯資料的兩票等於一票：金門重複建檔是兩票都看到資料庫標錯的縣市。出生年在 `identity_candidates` 裡抄得到，證明不了查過；「中選會查這個姓名回幾筆（`cec_hits`）、依出生年收斂成幾人（`cec_people`）」只有真的查過才拿得到。伺服器用同一個姓名打一次中選會 API 核 `cec_hits`（全部筆數或完全同名筆數都算，API 是子字串比對），對不上或沒帶退回 400、不算被拒；API 掛了照收、備註記「未核」。只核 N 不核 M（M 要判斷，交給代理）。合併門檻（3 個 IP）不動。當天量到的 130 筆退件裡有 15 筆是票數達標卻因指認不一致／判不出而退件，這條就是衝著它們｜錯了的代價：每張指認票多一次中選會查詢；若中選會 API 行為改變（例如開始分頁），`cec_hits` 會系統性對不上、指認票全被退回——看 `cec_count_mismatch` 的比例就知道。
